Where the calendar file comes from

Homebase — in the app, Settings → Calendar Sync. Turn Enable on, tick the locations, pick the Google account, then Sync now. The shifts land in that Google calendar.

To get them in here, open Google Calendar in a browser → Settings → the calendar Homebase writes to → Secret address in iCal format. Open that link in Chrome to save the .ics, then add the file above. Or paste the link into Fetch from a link — that only works if Google lets this page read it, which it usually does not.

Homebase syncs into a whole Google account, so dentist appointments and birthdays arrive with the shifts. The filter on the job in Setup is what keeps them out.
