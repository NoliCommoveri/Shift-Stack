Server

The Worker that fetches Homebase’s calendar every fifteen minutes and serves the feed ICSx⁵ subscribes to. It sends what this phone holds and reads back what the fetch found, so both jobs are on the Schedule and in the pay figures. Without it the app still works on the shifts entered here; the rest have to be carried by hand.

Danger zone

Start over clears jobs, shifts and settings — the whole store. While the app is still being built this is the intended way to move to a new data shape.

Undo a test on this phone

For testing against the real server on a phone that is not the one this is for. It cancels every event this app has put in a calendar, clears every row the server holds — the cron’s as well as this phone’s — checks that the feed really is empty, and only then wipes this device and forgets the token. In that order, because every step before the last one needs the token to work.

Puts the database back to the state a fresh deploy is in. Tidier, and it stops the cron writing so much as a refusal — but the next phone to hold the token must press “Set up the database” before its first push will land. Leave it unticked if he is being handed the app today.
